# EuroHub · Euroflex Divisórias

Sistema de demonstração — do orçamento à instalação, cada obra em um só lugar.

**Todos os dados são ilustrativos.** Nada é enviado para servidor: o que você cria
(pedidos, orçamentos, checklists) fica salvo apenas no seu navegador.

## Telas

- **Login** — entre com qualquer e-mail e senha (é uma demonstração)
- **Painel do gestor** — indicadores do mês, gráfico de pedidos e pedidos recentes
- **Orçamentos** — calculadora que atualiza materiais e total em tempo real; gera PDF, envia resumo por WhatsApp e converte em pedido
- **Pedidos** — quadro kanban: arraste os cartões entre as colunas ou clique neles
- **Projetos** — arquivos da obra e histórico de revisões
- **Verificação** — checklist técnico com divergência de medida; ao conferir tudo, libera para produção
- **Produção / Instalação / Clientes e obras** — acompanhamento das etapas

## Como rodar

É um site estático: basta abrir o `index.html` no navegador, ou acessar a versão
publicada no GitHub Pages.
